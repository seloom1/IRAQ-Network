# 🌐 دليل الخطوط والباقات والتطبيقات

ملف توثيقي يجمع المعلومات المقدّمة عن بعض الخطوط والباقات والتطبيقات، بما فيها أسماء المضيفات وعناوين IP والمنافذ المذكورة.

> ⚠️ **تنويه:** هذه المعلومات منقولة كما وردت ولم يتم اختبارها أو التحقق من صلاحيتها. هذا المستودع للتوثيق فقط، ولا يوصي بتجاوز قيود مزوّد الخدمة. يُرجى الالتزام بشروط مزوّد الخدمة والقوانين المعمول بها.

## 🟦 خط OODI

| التطبيق | المضيف | المنافذ | تفاصيل إضافية |
|---|---|---:|---|
| 💬 Telegram | `web.telegram.org` | `443` | ذُكر أن البوت يعمل عبر `TLS` على المنفذ 443. |
| 🗺️ Waze | `cres.waze.com` | `80`, `443`, `2053` | — |
| 🎮 تطبيق «بلي»* | عنوان Cloudflare كمثال: `104.18.26.180` | جميع المنافذ حسب الوصف الوارد | قائمة عناوين IP غير متوفرة، واسم التطبيق يحتاج تأكيدًا. |
| 𝕏 X / Twitter | `x.com` | `443` | — |
| 👻 Snapchat | `ccounts.snapchat.com`* | `443` | اسم المضيف كما ورد؛ يرجى تدقيقه، فقد يكون المقصود `accounts.snapchat.com`. |

## 🟥 خط آسيا سيل — Red + User

| الاستخدام المذكور | عنوان IP | المنافذ |
|---|---|---|
| 🎮 PUBG | `104.18.26.180` | `443`, `8443`, `8080`, `2083`, `80`, `8880`, `2096` |

وُصف عنوان IP بأنه عنوان Cloudflare من نوع «Clean IP» في المعلومات المقدّمة.

## 🟪 خط زين العراق — Free Social

| الباقة | المضيف | المنافذ |
|---|---|---|
| 📦 Viber Fiber | `crm-lp.viber.com` | `443`, `8443`, `8080`, `2083`, `80`, `8880`, `2096`* |

> المنافذ أعلاه هي نفس المنافذ المذكورة لقسم PUBG في خط آسيا سيل، بحسب المعلومات المقدّمة.

## 🟩 خط زين — باقة كفو

| التطبيق/الباقة | عنوان IP | المنافذ |
|---|---|---|
| 🎵 TikTok | `172.66.1.232` | غير مذكورة |

وُصف عنوان IP بأنه عنوان Cloudflare من نوع «Clean IP» في المعلومات المقدّمة.

## ⚠️ ملاحظات ونواقص

- لم تُرفق نتائج اختبار أو تاريخ ومكان للاختبار؛ لذلك لا يمكن تأكيد أن العناوين والمنافذ تعمل حاليًا.
- لم يُحدَّد ما إذا كانت المنافذ تستخدم `TCP` أم `UDP`.
- عبارة «جميع المنافذ» غير محددة، كما أن عنوان IP واحد لا يمثّل بالضرورة جميع عناوين Cloudflare.
- اسم التطبيق «بلي» يحتاج إلى توضيح، واسم مضيف Snapchat يحتاج إلى تدقيق.
- منافذ TikTok على خط زين/كفو غير مذكورة.
- لا توجد في المعلومات المقدّمة ثغرات أمنية مثبتة؛ هذه ملاحظات توثيقية وليست نتائج فحص أمني.

### 📝 المساهمة والتحديث

إذا أُضيفت معلومات جديدة، يُفضّل إرفاق مصدرها وتاريخ التحقق ونوع الاتصال (`TCP` أو `UDP`) حتى تبقى القائمة واضحة وقابلة للمراجعة.
