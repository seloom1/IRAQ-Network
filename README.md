## عن المشروع

يهدف هذا المستودع إلى ترتيب ملاحظات عامة عن أسماء الخطوط والباقات والخدمات المرتبطة بها، مع توضيح أن أي معلومة عن توفر خدمة ضمن باقة يجب التأكد منها مباشرةً من شركة الاتصالات.

## حدود الاستخدام

- لا يتضمن المستودع إعدادات أنفاق أو بروكسي أو تجاوز فوترة/قيود الشبكة.
- لا ينشر عناوين IP أو قوائم منافذ أو نقاط اتصال غير موثّقة.
- أسماء النطاقات والخدمات وسياسات الباقات قد تتغير؛ راجع الموقع أو الدعم الرسمي لمزوّد الخدمة قبل الاعتماد على أي معلومة.
- استخدم الخدمات وفق شروط مزوّد الخدمة والقوانين المحلية، ولا تختبر أو تستغل ثغرات دون تصريح مكتوب.

## المساهمة والتحديثات

عند اقتراح تحديث، أرفق مصدرًا رسميًا وتاريخ التحقق واسم الشركة/الباقة. لا تضع بيانات شخصية أو أسرار حسابات أو إعدادات هدفها تجاوز قيود الاستخدام.
